# 相図

> [英語原本](PHASE_DIAGRAM.md)の参考訳。領域と数式の定義は原本を正本とする。

RCWEは、対象の二者に偽りの精密さを持つパラメータラベルを付ける前に、領域を分類する。

## 領域

- **E — 安定平衡**：軌道が内部平衡へ減衰する。
- **O — 振動**：limit cycleの領域。超臨界と亜臨界の発生を区別する。
- **M — 多重安定／履歴依存**：複数の関係modeが共存し、履歴や初期条件がbasinを選ぶ。
- **L — チャネルlock／escape**：有限な内部領域から離れ、`p_D`が0または1へ向かう。自動的に「破局」や「交際成立」を意味しない。
- **B — 分岐境界**：Hopf、saddle-node、Bautinなどの境界領域。

## 主要な構造的結果

`R<1/4`で

\[
R<\Delta<1-R
\]

なら有限平衡点が一意に存在する。`G_H`より下では安定で、Hopf候補面で安定性を失う。

`1/4<R<1/2`では複数の平衡点があり得る。対称な場合は

\[
t=0,\qquad t=\pm\sqrt{4R-1}
\]

で、中央の平衡点はseparatorとなる。二重安定性と履歴依存が起こり得るため、`G`だけでは力学を分類できない。

対称な場合に`R>=1/2`なら中央の有限平衡はsaddleであり、一般の軌道はチャネルlockへescapeし得る。

## 解釈上の限界

相ラベルが表すのは数学的なチャネル力学である。それだけで好意、道徳的価値、関係の成功、作品genreは判定できない。
