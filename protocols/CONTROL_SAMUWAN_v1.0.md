# Prospective control — Samuwan Herutsu v1.0

## Purpose

This control asks whether RCWE can correctly avoid detecting oscillation when a relationship is comparatively stable. Only material unread at the freeze date is eligible for prospective scoring; previously discussed material is development data.

## Procedure

1. Record the exact publication/episode boundary at freeze time before opening new material.
2. Use the same IE definition, four-channel codebook, provenance fields, two-coder blind process, and reliability gates as the main studies.
3. Analyse consecutive IEs rather than selecting romantic highlights.
4. Freeze the expected phase as stable-equilibrium/low-AC (`E`) unless the pre-holdout record justifies another label.
5. Compare RCWE with persistence and a simple narrative-position baseline using prequential scoring.
6. Report channel AC power and romantic-tension ratings under the Tension Bridge protocol.

## Control prediction

The unread segment should not show sustained event-free alternating approach/withdrawal, repeated large event-free channel jumps, or channel locking. Persistence should remain difficult to beat. If strong oscillation is reproducibly observed, record control failure rather than redefining the work as a non-control.
