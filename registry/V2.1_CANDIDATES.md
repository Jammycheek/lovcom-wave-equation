# RCWE v2.1 candidate registry

These ideas are quarantined from v2.0 validation. Inclusion requires repeated evidence, identifiable parameters, and a new freeze.

1. **Persona-conditioned channel valuation** — context labels such as a stable persona mode may alter channel values.
2. **State-dependent intervention nodes** — an observer/intervener changes event rate after observing pair states.
3. **Direct inter-pair coupling / Network RCWE** — only after shared events and endogenous mediation fail, with repeated predictive cross-lags.
4. **Constraint action-point taxonomy** — constraints may act on interaction access, transition feasibility, disclosure, or another distinct mechanism.
5. **Separate character-volatility process** — individual emotional motion may be modelled without contaminating dyadic channels.
6. **Static-tension state** — required only if high romantic tension reproducibly occurs with negligible channel AC power.
7. **Explicit marked event process** — a predeclared model for event rates and marks, fitted without post-hoc signs.
8. **Full four-channel value functions** — a unique, implementable `V_k` family that closes the complete simplex dynamics.

Candidate status is not evidence. Each proposal must name a falsifying observation before promotion.
